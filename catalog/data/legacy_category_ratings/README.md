# Блоки рейтингов старой Madloba

Тексты и 9 исходных изображений для 16 категорий получены 15 сентября 2026 года из локальной старой Madloba (`madloba.info`). Код и стили старого сайта не используются.

В `banners.json` категории и назначения ссылок указаны через `url_path`. Числа в исходном HTML — идентификаторы старой базы; команда импорта заменяет их идентификаторами страниц новой базы. Переносить этот HTML напрямую в редактор нельзя.

## Применение

После резервного копирования базы и применения миграций:

```sh
python manage.py import_legacy_category_ratings
python manage.py import_legacy_category_ratings --apply
```

Первый вызов проверяет данные без изменений. Второй импортирует изображения и публикует настройки категорий. Уже настроенные блоки пропускаются. Если отсутствует категория, страница назначения или изображение, либо есть неопубликованный черновик категории, импорт останавливается до записи данных.

После импорта блок редактируется в категории организации, в разделе «Популярные рейтинги». Для показа нужны изображение и текст. Он выводится у всех организаций категории независимо от подписки.

## Остальные изменения

- На странице организации перед отзывами выводится общий баннер премиального размещения с исходными текстами и изображением старого сайта; кнопка ведёт на `/premium-contacts/` с учётом языка.
- На Blog index page баннеры добавляются после подзаголовка, на странице организации — перед общим баннером. Поля «Баннеры» переведены на языки контента. В организации они находятся на вкладке «Описание».
- Подзаголовок Blog index page поддерживает ссылки через редактор Wagtail. Миграция сохраняет буквальное содержимое существующих подзаголовков и их ревизий. Обратное преобразование миграцией отключено: новые ссылки и длинные тексты нельзя без потерь вернуть в прежнее поле из 255 символов.
- Карточки конкурентов выбираются из той же категории: до четырёх опубликованных публичных организаций с действующим тарифом Premium. Порядок случайный. Любая действующая платная подписка текущей организации скрывает эти карточки. Подписка должна быть включена и действовать на текущую дату включительно.
- Короткие ссылки WhatsApp, Viber, TikTok и ссылки на карты распознаются при выводе соцсетей. Для карт используются отдельные иконки Google и Яндекса из старого проекта.

## Проверки

На локальной базе применены четыре миграции, перенесены 16 блоков с 9 общими изображениями. Перед изменениями создана полная резервная копия PostgreSQL. Проверено соответствие ссылок и изображений в сохранённых ревизиях; повторный запуск импорта не добавляет данные.

Запущены тесты Django, `check`, `makemigrations --check --dry-run`, Ruff для изменённых Python-файлов, Pyright для новых рабочих модулей и миграции данных, `npm run build`, `git diff --check`. В браузере проверены платная и бесплатная организации, блок рейтингов, общий баннер, иконки соцсетей и карт, а также несохранённый пример баннера и ссылки в подзаголовке блога. Проверены ширины 375, 767, 768, 991, 992 и 1400 px.

Штатный Stylelint останавливается на существующей настройке `ignoreProperties: ["composes"]`. Новый SCSS дополнительно проверен с временным отключением несовместимого правила `declaration-property-value-no-unknown`; остальные правила прошли. Сборка Webpack завершилась с тремя предупреждениями о размере пакетов и рекомендациях по разделению кода.
