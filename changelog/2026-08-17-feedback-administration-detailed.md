# Обновление отзывов и комментариев

- **Дата:** 17 августа 2026 года
- **Коммит:** [`5838c96`](https://github.com/hardcodd/new.madloba.info/commit/5838c96548de441f0c9f6724d00dd630e80117bd)
- **Статус:** завершено

## Что сделано

- Отзывы и комментарии собраны в отдельные разделы административного меню.
- В списках отображаются автор, текст, статус, связанная страница и дата создания.
- Для отзывов дополнительно виден рейтинг, для комментариев — признак закрепления.
- Действия модерации доступны непосредственно из списка.
- Добавлен пакетный импорт CSV без перезагрузки страницы.
- Большие файлы отправляются частями по 100 записей.
- Каждая строка получает отдельный результат: импортирована, уже существует или содержит ошибку.
- Проверяются обязательные поля, дата, рейтинг, страница и права сотрудника.
- Повторная загрузка не создаёт дубликаты.
- Сохраняются исходные даты публикации и существующие данные пользователей.
- Пересчёт рейтингов выполняется один раз для группы импортированных отзывов.
- Добавлены русские переводы новых сообщений интерфейса.

## Безопасность

- Импорт доступен только сотрудникам с соответствующими правами.
- Сервер повторно проверяет все данные.
- Контрольная сумма внешней библиотеки обработки CSV проверена и зафиксирована.

## Проверка

Добавлено 26 автоматических проверок для импорта, прав доступа, дубликатов, дат, рейтингов, меню и административных списков. В полном наборе все 30 тестов проекта прошли успешно.

Также успешно выполнены проверки кода, шаблонов, JavaScript и production-сборка статических файлов.

## Что учесть

Обработка CSV в браузере использует внешний сервис доставки библиотеки. Если он недоступен из сети сотрудника, импорт не запустится до восстановления доступа.
