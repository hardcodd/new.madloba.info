# Исправление пропорций изображений

- **Дата:** 20 августа 2026 года
- **Коммит:** [`b057971`](https://github.com/hardcodd/new.madloba.info/commit/b05797178f6223eaeeeb849bae8a0f4188892e21)
- **Статус:** завершено

## Что изменено

- Для изображений организаций, публикаций блога и рейтингов заданы варианты 16:9 размером 720×405 пикселей.
- Для квадратных карточек заданы варианты 402×402 пикселя, для вертикальной карточки — 402×495 пикселей.
- Изображение страницы 404 приведено к размеру 400×371 пиксель.
- Логотипы приведены к размерам 120×28 и 40×25 пикселей, иконки языков — к размеру 20×20 пикселей.
- Обложка видео для структурированных данных приведена к размеру 1200×675 пикселей.

Во всех этих местах масштабирование только по ширине заменено подготовкой изображения под точные размеры блока. Лишняя часть исходного изображения при необходимости обрезается средствами Wagtail.

## Зачем

Подготовленное изображение теперь соответствует фактическим пропорциям элемента интерфейса. Это делает размеры вариантов предсказуемыми и не оставляет браузеру изображение с неподходящим соотношением сторон.

Изменения затрагивают только шаблоны. Серверная логика, модели и база данных не менялись.
