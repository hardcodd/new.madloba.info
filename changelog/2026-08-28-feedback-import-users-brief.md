# Улучшил импорт пользователей в отзывах и комментариях

- **Дата:** 28 августа 2026 года
- **Коммит:** [`916a1cd`](https://github.com/hardcodd/new.madloba.info/commit/916a1cde56cc802bd6f9773329feb4551c62ffd5)

Сделал импорт отзывов и комментариев удобнее: теперь можно загрузить запись только с именем человека, без отдельного имени пользователя. В таком случае сайт сам создаёт понятное служебное имя пользователя и повторно использует уже созданного человека при следующих импортах.

Это уменьшает ручную подготовку данных и снижает риск дублей. Одинаковая логика теперь используется и для отзывов, и для комментариев, поэтому поведение стало предсказуемее.

Проверил импорт автоматическими тестами: 27 тестов прошли успешно. Также проверил Django, Ruff, отдельную проверку типов нового файла и форматирование diff.
