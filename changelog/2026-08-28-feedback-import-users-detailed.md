# Пользователи при импорте отзывов и комментариев

- **Дата:** 28 августа 2026 года
- **Статус:** завершено
- **Коммит:**
  - [`916a1cd`](https://github.com/hardcodd/new.madloba.info/commit/916a1cde56cc802bd6f9773329feb4551c62ffd5) — общая обработка пользователей для импорта отзывов и комментариев.

## Что изменилось

- Вынесена общая логика разбора и создания импортируемого пользователя в `core/import_users.py`.
- Формат `Полное имя / username` сохранён: если username указан явно, импорт использует существующего пользователя или создаёт нового с этим username.
- Добавлен импорт только по полному имени без username.
- Для такого импорта сначала ищется уже созданный импортный пользователь с префиксом `m_` и тем же полным именем.
- Если подходящего пользователя нет, создаётся новый username в формате `m_<случайное число>_<имя латиницей>`.
- При конфликте с уже занятым сгенерированным username импорт пробует другой номер.
- Ошибка генерации уникального username вынесена в переводимые сообщения.

## Почему это нужно

Импорт отзывов и комментариев раньше требовал username в данных либо использовал имя как username. Для русских ФИО это неудобно и повышает риск грязных служебных аккаунтов. Новая логика позволяет импортировать данные по обычному имени человека, а техническое имя пользователя создавать автоматически.

## Надёжность и поддержка

- Одинаковый код теперь используется в импорте отзывов и комментариев, поэтому поведение не расходится между двумя разделами.
- Создание пользователя осталось защищено транзакцией и обработкой конфликта уникального username.
- Тестами покрыты явный username, повторное использование импортного пользователя, генерация username и повторная попытка при конфликте.
