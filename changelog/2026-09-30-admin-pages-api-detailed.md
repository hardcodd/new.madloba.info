# Расширенный список страниц в API админки

- **Дата завершения задачи:** 30 сентября 2026 года
- **Статус:** изменения завершены в коде; отчёт составлен 30 сентября 2026 года.
- **Коммит:** [5662dfa](https://github.com/hardcodd/new.madloba.info/commit/5662dfab14e315b28b4aa3da46eddabc1d12410b)

## Что изменилось

- Максимум для `?limit=` увеличен до 100; значение по умолчанию осталось 20. Запрос со значением выше 100 отклоняется.
- Список страниц дополнен полями `image`, `noindex`, `has_unpublished_changes`. Превью отдаётся как адрес, ширина и высота; размер выбирается по типу страницы. Для неподходящего или отсутствующего изображения возвращается пустое значение.
- Превью подготавливаются пакетно для одной страницы результатов. Для прямого открытия адреса в браузере API возвращает JSON.
- Сохранено штатное ограничение доступа админки.

## Проверка

Тесты проверяют доступ администратора и отказ другим пользователям, лимиты 20/100/101, поля ответа, размеры для разных типов страниц и обработку SVG. На текущем состоянии 30 сентября прошли 241 тест, проверка Django и проверка отсутствия новых миграций.

## Ограничения

Время ответа на больших реальных данных и работа внешнего потребителя API отдельно не замерялись.
